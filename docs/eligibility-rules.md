# Eligibility rules

The grant is only available to homeowners or landlords. The property must be in the UK.

## Per answer

| Question | Answer | Effect |
|---|---|---|
| Property type | Flat or maisonette | Not eligible (ends the journey) |
| Property type | Any other type | No effect |
| Ownership | I own and live in it | No effect |
| Ownership | I own it and rent it out (landlord) | No effect |
| Ownership | I rent from a private landlord | Not eligible (ends the journey) |
| Ownership | I rent from a council or housing association | Not eligible (ends the journey) |
| Household income | Under £30,000 | No effect (fully eligible) |
| Household income | £30,000 to £50,000 (exactly £30,000 and exactly £50,000 are in this band) | Partially eligible |
| Household income | Over £50,000 | Not eligible (does not end the journey) |
| Current heating | Gas boiler, oil boiler | No effect |
| Current heating | Electric | Partially eligible |
| Current heating | Heat pump already installed | Not eligible |

## Combining the answers

1. Any "not eligible" answer gives **not eligible**.
2. Otherwise, any "partially eligible" answer gives **partially eligible**.
3. Otherwise **eligible**.

The result lists every reason that applies.
